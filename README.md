# Book Catalog API — электронный каталог книг

## Описание проекта

Book Catalog API — учебное веб-приложение на Python, разработанное с использованием FastAPI в рамках дисциплины «Инфраструктура и администрирование».

Приложение предназначено для просмотра и поиска книг в небольшом электронном каталоге.

**Основные возможности:**
- Просмотр всех книг.
- Поиск книги по идентификатору (ID).
- Поиск книг по названию или автору.
- Фильтрация книг по жанру.
- Получение информации о библиотеке.
- Проверка работоспособности приложения и его версии.
- Логирование основных событий.

Каталог книг хранится в памяти приложения, без использования базы данных.

## Используемые технологии

- **Python 3.11** — язык программирования.
- **FastAPI** — создание API.
- **Uvicorn** — запуск веб-сервера.
- **python-dotenv** — загрузка переменных окружения.
- **pytest** — автоматическое тестирование.
- **httpx** — выполнение HTTP-запросов в тестах.
- **Git и GitHub** — контроль версий и хранение проекта.
- **GitHub Actions** — автоматический запуск тестов (CI).

## Установка и запуск

### 1. Установка зависимостей

```powershell
python -m pip install -r requirements-dev.txt
```

### 2. Настройка переменных окружения

Создать файл `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

В файле `.env` можно указать название библиотеки:

```dotenv
LIBRARY_NAME=Моя библиотека
```

Если переменная не задана, используется стандартное название «Моя библиотека».

### 3. Запуск приложения

Для разработки с автоматической перезагрузкой:

```powershell
python -m uvicorn app_final:app --reload
```

Для обычной работы без автоматической перезагрузки:

```powershell
python -m uvicorn app_final:app
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000

Интерактивная документация Swagger UI:

http://127.0.0.1:8000/docs

Для остановки сервера используется сочетание `Ctrl+C` в терминале.

## Маршруты API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | Проверка работоспособности |
| GET | `/version` | Получение версии приложения |
| GET | `/books` | Получение списка всех книг |
| GET | `/books/{book_id}` | Поиск книги по ID |
| GET | `/books/search?query=...` | Поиск по названию или автору |
| GET | `/books/genre/{genre}` | Фильтрация по жанру |
| GET | `/library-info` | Информация о библиотеке |

### Примеры запросов

Получить все книги:

`http://127.0.0.1:8000/books`

Найти книгу с ID 1:

`http://127.0.0.1:8000/books/1`

Найти книги Михаила Булгакова:

`http://127.0.0.1:8000/books/search?query=Булгаков`

Найти книги жанра «фантастика»:

`http://127.0.0.1:8000/books/genre/фантастика`

Если книга по указанному ID не найдена, приложение возвращает HTTP-код `404`.

## Автоматическое тестирование

Для проверки приложения используются автоматические тесты на pytest.

Тесты проверяют:
- Работу `/health` и `/version`.
- Получение списка книг.
- Поиск книги по ID.
- Обработку отсутствующей книги.
- Поиск по автору.
- Обработку некорректного поискового запроса.
- Фильтрацию по жанру.
- Обработку отсутствующего жанра.
- Получение информации о библиотеке.

Запуск тестов:

```powershell
python -m pytest -v
```

При успешном выполнении все 10 тестов получают статус `PASSED`.

## Логирование и диагностика

Основные события приложения записываются в логи и выводятся в терминале, в котором запущен Uvicorn.

Логируются запуск и остановка приложения, обращения к маршрутам, результаты поиска и предупреждения об отсутствующих книгах.

### Проверка работоспособности

Открыть:

http://127.0.0.1:8000/health

Ожидаемый ответ:

```json
{
  "status": "ok"
}
```

### Проверка версии

Открыть:

http://127.0.0.1:8000/version

Ожидаемый ответ:

```json
{
  "version": "1.1.0"
}
```

## Автоматическая проверка GitHub Actions

В проекте предусмотрена настройка CI с помощью GitHub Actions.

Workflow запускается при событиях `push` и `pull_request` и выполняет следующие действия:

1. Получает исходный код репозитория.
2. Устанавливает Python и зависимости.
3. Запускает автоматические тесты через pytest.
4. После успешной проверки создаёт artifact `book-catalog-source` с файлами приложения.

Конфигурация находится в `.github/workflows/ci.yml`.
